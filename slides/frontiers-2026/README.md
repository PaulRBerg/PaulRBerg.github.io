# PRB Agent Skills — Frontiers 2026

To start the [Slidev](https://github.com/slidevjs/slidev) show from the repository root:

- `bun install --frozen-lockfile`
- `bun run slidev slides/frontiers-2026/slides.md`
- visit <http://localhost:3030>

Edit the [slides.md](./slides.md) to see the changes.

Use `just dev` to develop the complete site. Run `bun run build:slides` to rebuild the Slidev decks
or `just build` to build the complete site into `dist/`. Push to `main` to publish through GitHub
Pages.

Learn more about Slidev at the [documentation](https://sli.dev/).
